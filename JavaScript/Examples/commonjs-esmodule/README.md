# CommonJS vs ES Modules Examples

## CommonJS

```bash
node JavaScript/Examples/commonjs-esmodule/commonjs/app.cjs
```

- Export bằng `module.exports`.
- Import bằng `require()`.

## ES Modules

```bash
node JavaScript/Examples/commonjs-esmodule/esm/app.mjs
```

- Export bằng `export`.
- Import bằng `import`.
- Named export dùng `{}`.
- Default export không dùng `{}`.
